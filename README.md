# ai-novel

Working repository for the ZenithCite AI-assisted web novel production system.

## Contents

| Path | What it is |
| --- | --- |
| `sop/novel_sop.md` | The governing production SOP, Parts A through F: seed development, blueprint, chapter drafting, chapter editing, cover generation, platform submission. This is the canonical version. |
| `novel-1/Novel_1_1.md` | Novel 1 ("Rejected by the Alpha" / the Wren Ashveil story). Contains the overview and bibles, the full 350-chapter outline in 10 batches, an older embedded copy of the SOP, the drafted chapters, and the ledger deltas. |
| `context/project_memory.md` | Carried-over project memory: current state, standing rules, production sequence, feedback conventions. |

## Standing hard rules

- No em dashes or en dashes anywhere, in prose or in SOP text.
- Paragraphs cap at 3 sentences.
- Word count is verified programmatically, never estimated. Target 1,000 to 1,500 words per chapter.
- Every chapter ends on a cliffhanger.
- Every chapter outputs a Ledger Delta.
- Never invent detail that is not in the outline or bible. Flag instead.
